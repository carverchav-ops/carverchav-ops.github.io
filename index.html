About Me

Hi, I'm Carver. I'm a developer who builds free VST audio plugins in C++ with the JUCE framework.

For about three years I've been making plugins with a community of developers on Discord. That's where I learned JUCE and got into DSP and real-time audio. I also make my own music, so I care about how a plugin sounds as much as how the code works.

Featured Plugin: Chorus

CHORUS

I led a chorus plugin built on my own idea. Most chorus effects use an LFO to wobble a delay line. This one gets its thickness from how several voices interact with each other, like tape machines running slightly out of sync.

  • Phase interactions between voices
  • Micro-pitch shifting
  • Tape-style multi-voice modeling
