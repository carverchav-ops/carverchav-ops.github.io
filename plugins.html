Latest Project: Metallic Granular Plugin NEW!

GRANULAR
Status: released

My newest plugin chops sound into tiny grains and runs them through super fast pitched delays. When delay lines get that short, they stop sounding like echoes and start ringing, so the output turns metallic and resonant.

  • Granular processing
  • Very short, pitch-shifted delays
  • Metallic, ringing textures

Chorus

CHORUS

I led a chorus plugin built on my own idea. Most chorus effects use an LFO to wobble a delay line. This one gets its thickness from how several voices interact with each other, like tape machines running slightly out of sync.

  • Phase interactions between voices
  • Micro-pitch shifting
  • Tape-style multi-voice modeling
